## Theme submodule

`themes/minos` is a fork whose upstream ([ppoffice/hexo-theme-minos](https://github.com/ppoffice/hexo-theme-minos)) is **publicly archived**. There will never be an upstream pull or PR, so treat the fork as owned code: edit it freely, and never weigh "keeping the fork rebaseable against upstream", "this belongs upstream", or "send this fix upstream" when deciding where a change goes. Judge a theme edit on whether it is right for this blog, nothing else.
